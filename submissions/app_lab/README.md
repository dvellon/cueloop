# CueLoop App Lab submission package

This directory contains the judge-facing source copy for **Invent the Future with Arduino UNO Q and App Lab**. It is a publication workspace, not a record of results that have not happened.

## Publish from these files

| Hackster field or asset | Source |
|---|---|
| Title, subtitle, tags, category | `SUBMISSION_METADATA.md` |
| Full project story and build instructions | `PROJECT_ARTICLE.md` |
| Source-code orientation | `SOURCE_GUIDE.md` |
| Troubleshooting | `TROUBLESHOOTING.md` |
| Three-minute video and cutdowns | `VIDEO_PACKAGE.md` |
| Photos/screenshots to capture | `PHOTO_SHOT_LIST.md` |
| Truthful result table | `TEST_RESULTS.md` |
| Judging-criteria evidence audit | `RUBRIC_REVIEW.md` |
| Media/source credits | `LICENSES_AND_ATTRIBUTION.md` |
| Final account-controlled actions | `SUBMISSION_CHECKLIST.md` |

The authoritative detailed procedure/observation log is repository-root `HARDWARE_TESTS.md`; `HARDWARE_RESULTS.md` is its reviewed publication summary. Copy measured values into submission copy only after both preserve hardware revision, conditions, units, evidence tier, and pass/fail status.

## Release attachments

Attach these artifacts after checking their SHA-256 sidecars:

1. the self-contained Arduino App Lab import archive generated by `scripts/package_app_lab.py`;
2. the clean source release generated by `scripts/package_source_release.py`;
3. the readable SVG schematic from `hardware/schematics/cueloop_v1.svg`;
4. the final video or its stable public link.

Do not attach the downloaded model separately, raw evaluation audio, databases, credentials, build trees, or private working files. The App Lab archive contains the verified model only because it is required at runtime; its internal manifest records the digest and upstream license.

## Publication rule

Renderings, simulator screens, development-host measurements, UNO Q measurements, and physical CuePod measurements must remain explicitly labeled. If a physical gate fails before the deadline, publish the failure and narrow the claim or vocabulary; never replace it with a simulated success.
